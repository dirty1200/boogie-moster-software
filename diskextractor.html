Disk Extractor

> Extracts audio samples from Roland W-30/S-330 disk images.

Main Purpose

  • Reads Roland disk image files (from vintage samplers).
  • Extracts individual sounds/samples stored on those disks.
  • Converts them to standard WAV files you can use in modern software.

Key Features

Format Support

  • Roland W-30 disk images
  • Roland S-330 disk images
  • Roland S-550 disk images
  • Roland S-50 disk images
  • Supports .img, .dsk, .w30, .out file formats

Audio Conversion

  • Converts 12-bit packed samples to 16-bit WAV
  • Preserves original sample rates (30kHz or 15kHz)
  • Optional resampling to 44.1kHz using SoX

Batch Processing

  • Extract individual tones or all tones at once
  • Shows tone information (name, duration, sample rate, memory bank)

User Interface

  • GUI with file selection
  • Tone list with details
  • Activity log
  • Progress tracking

Typical Workflow

  1. Select a Roland disk image file
  2. View all tones/samples on the disk
  3. Choose an output folder
  4. Extract selected tones or all tones
  5. Get standard WAV files ready for use
